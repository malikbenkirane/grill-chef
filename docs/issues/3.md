# Round payload domain (JSON contract)

## Context

The `grill_round` tool sends only the current round's data to the server. Earlier rounds live in state; screens render from state. The contract now lives as Go domain code, not as embedded JSON examples: the domain is pure, JSON is an adapter (`internal/port/round/json`, built with #5).

Referenced in grill rounds: R3 (Q3.3 drive_round sends current round only), R4 (Q4.3 structured envelope + markdown inline boundary), plus the issue-3 grilling session (schema confirmed via legend).

## Deliverables

- `internal/domain/round`: rounds (`QuestionRound` / `LegendRound` sum types), questions, choices (1-based, 0 = other/none, -1 = skip), answers and answer sheets, `Markdown` type making the structural/markdown boundary compiler-checked, `Validate()` invariants with sentinel errors, `SchemaVersion` const.
- `internal/domain/session`: the grill descriptor (`Active | Closed`, guarded `Close()`); no daemon/pid state — the db is the real host of session state, one stateless daemon hosts all sessions.
- `docs/drafts/contract.md`: the contract prose (wire + domain halves), citing `docs/drafts/initial_mockup/rounds.md` as the decision log.

## Amendments of earlier documents

- No round cap: frontier closure is the only termination (amends the mockup's documented 5-round cap). Question/option caps stay tool policy (#5).
- Legend and question rounds are separate types; `frontier_remaining` is numeric (`Served`/`Retained`); active/closed session states only.

## Acceptance criteria

- A `QuestionRound` can express every element of grill-me's round format (intro, recap branches with numeric frontier counts, question blocks with abstract, options, recommendation, reminders); a `LegendRound` expresses the per-branch tagged bullets.
- `AnswerSheet` carries enough information for the agent to recompute the frontier (choice, skip, other, comments per question).
- Every type's `Validate()` catches its own invariants; violations are sentinel errors (`errors.Is`-able).
- Domain packages import nothing beyond stdlib (`errors`, `fmt`, `strings`); `encoding/json` stays out of `internal/domain`.
- Table-driven tests cover every exported validator and `String()` method; `go test ./... && go vet ./...` passes.

## Dependencies

None as a design base — #1, #4, #5, #8, #10, #11, #13 and #15 depend on this contract; `docs/issues/19.md` (payload version validator) extends it.
