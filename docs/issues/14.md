# Station home route

## Context

The station home (`/` route) is the global context surface: it lists pending sessions (multiple agents may be grilling simultaneously), historical sessions, and provides a dismiss affordance to clear entries. The per-grill sidebar (issue 8) stays single-focus (rounds of the current session only); all cross-session management lives here.

Referenced in grill rounds: R2 (Q2.3 pending sessions in sidebar, session history, dismiss), R3 (Q3.5 per-grill sidebar is rounds-only; global list moves to station home `/`).

## Requirements

- Route: `/` (station home).
- Content:
  1. **Pending sessions**: sessions with status `active` and at least one pending round. Each entry shows:
     - Session name (human-readable, from `grill_start`).
     - Session id (truncated for display).
     - Current round number.
     - A link to `/s/<id>/` (jumps to the session).
  2. **Session history**: sessions with status `closed`. Each entry shows:
     - Session name.
     - Date closed.
     - A link to `/s/<id>/legend` (view the legend).
  3. **Dismiss affordance**: a button per session (pending or historical) that removes it from the station home listing. Dismissal clears the session from the UI but does not delete the state record (data preservation); a dismissed session can be undeleted by direct URL access. Alternatively, dismissal hard-deletes from state — this is an implementation decision, but the mockups show a "dismiss" action.
- `grill-chef ui` subcommand opens the station home in the browser.
- No planned-round placeholders anywhere on the station home (frontier is answer-dependent; showing future rounds would add noise and bias).
- Tailwind-styled (issue 9): cards for sessions, clear visual separation between pending and history sections.

## Dependencies

- Issue #1 (state database — session list and status)
- Issue #8 (HTML routes — station home route)
- Issue #9 (Tailwind — styling)

## Acceptance criteria

- Visiting `/` shows all active sessions and closed sessions.
- Pending session entries link to the correct `/s/<id>/` URL.
- History entries link to the legend screen.
- Dismiss removes a session from the listing.
- No planned-round placeholders are shown.
- `grill-chef ui` opens `/` in the browser.
