# Legend & closing screen

## Context

When the frontier is empty (all branches of the design tree visited), the agent sends a final `grill_round` call with a `legend` payload instead of a round payload. The browser renders a legend screen with per-branch tagged bullets. The shared-understanding confirmation stays exclusively in chat (grill-me rule preserved). The session is then marked `closed` and archived in the station home (issue 14).

Referenced in grill rounds: R4 (Q4.4 legend via final optional payload, browser renders legend screen, confirmation stays in chat), R5 (legend closing confirmed).

## Requirements

- Route: `/s/<id>/legend` renders the legend screen.
- The legend payload (issue 3 schema) contains:
  - A title (tree topic).
  - Per-branch sections, each with tagged bullets (`{tag, decision}` where decision includes "because <reason>").
- The legend screen displays:
  - The tree topic as a heading.
  - Each branch as a section with its title.
  - Each bullet showing the tag as a chip and the decision text (markdown rendered).
- After the legend renders:
  1. The session status changes to `closed` in state (issue 1).
  2. The `grill_round` tool call (issue 5) returns immediately (no blocking — the legend is informational).
  3. The session appears in the station home's history list (issue 14).
- The shared-understanding confirmation (grill-me's "wait for the user to confirm") stays in the chat, NOT in the browser. No "Confirm" button on the legend screen.
- The legend screen is immutable (same as past rounds, issue 12).

## Dependencies

- Issue #3 (JSON schema — legend payload shape)
- Issue #5 (grill_round — accepts legend payload, returns immediately)
- Issue #8 (HTML routes — /legend route)
- Issue #11 (recap & submit — legend follows the last submitted round)

## Acceptance criteria

- A legend payload renders a per-branch tagged-bullet screen.
- The session is marked `closed` after the legend renders.
- The tool call returns immediately (no blocking wait).
- No "Confirm" button on the legend screen; confirmation stays in chat.
- The closed session appears in the station home history.
- The legend screen is immutable (no edit widgets).
