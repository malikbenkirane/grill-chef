# Issue 11 — Round recap & submit flow

## Context

Screen E is the recap/submit screen. After the user answers all questions
in a round, they review their choices and comments, then submit. Submission
freezes the round's answers as immutable and unblocks the `grill_round` tool
call (issue 5), returning answers to the agent.

Referenced in grill rounds: R1 (Q1.1 server owns all state, agent receives
answers on submit), R3 (Q3.4 review on submission screen, submission
requires all answered), R5 (Q5.3 immutability at submit).

## Requirements

### Recap display (screen E)

- Show all questions of the current round with:
  - The question title.
  - The selected choice text (or "Skipped" if skipped).
  - All comments attached to the question (rendered as text).
- "Other" selections show the "Other" label plus the comment text.
- Skipped questions show a "Skipped" badge.

### Submit gating

- The submit button is disabled until all questions have either a choice or
  are marked as skipped.
- On submit:
  1. All answers are frozen as immutable in state (issue 1).
  2. The round status changes to `submitted` in state.
  3. The `grill_round` tool call (issue 5) unblocks and returns the round
     result (issue 3 schema) to the agent.
  4. The browser navigates to either:
     - The next round's intro screen (if the agent sends another
       `grill_round`), or
     - The legend screen (issue 13) if a legend payload was sent.

### Editing before submit

- The user can navigate back to any question in the current round via the
  sidebar and edit their choice/comments before submitting.
- Once submitted, answers are immutable — no editing is possible on this or
  any past round (issue 12).

## Dependencies

- Issue 3 (JSON schema — result payload)
- Issue 5 (grill_round — unblocks on submit)
- Issue 8 (HTML routes — /final route, submit endpoint)
- Issue 10 (question widgets — answers come from these)

## Acceptance criteria

- Recap screen shows all questions with selected choices and comments.
- Submit is disabled until all questions are answered or skipped.
- Submit freezes answers, marks round as submitted, unblocks the tool call.
- Answers are immutable after submit — no edit affordance on past rounds.
- Back-navigation to edit works before submit; is blocked after.
